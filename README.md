# Galaxia amarilla ✨

Experiencia interactiva de flores amarillas con partículas doradas, corazón luminoso y frases tiernas únicas.

## Verla

Abre `index.html` directamente en el navegador. También puedes activar GitHub Pages desde **Settings → Pages** usando la rama `main` y la carpeta `/ (root)`.

Pulsa cada flor para descubrir su mensaje.
